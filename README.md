# Student Management System — Backend

A REST API built as a **learning project** using Node.js, Express, PostgreSQL, and Zod.

The main goal was to understand how a backend is structured, how APIs communicate with a database, and how a frontend and backend work together in a full-stack application.

## Tech Stack

* Node.js
* Express.js
* PostgreSQL
* SQL
* Zod
* REST API

## What I Built

* User registration and login
* Student CRUD operations
* Student search
* Pagination
* Input validation
* PostgreSQL database integration
* Authentication
* Modular API structure
* Error handling

## What I Learned

This project helped me understand:

* Building REST APIs with **Node.js and Express**
* Working with **PostgreSQL and SQL**
* Designing and writing database queries
* Structuring a backend using routes, controllers, services, and models
* Validating API input with Zod
* Implementing authentication
* Handling pagination and search
* Connecting a frontend to a backend API
* Debugging database and server-side errors
* Keeping backend code **organized, reusable, and clean**
* Understanding the complete flow:

```text
Frontend → API → Controller → Service → Database
```

Most importantly, I learned how to **structure and organize a larger project instead of putting everything into a few files**.

## Project Status

**Paused — Learning Project**

This project was intentionally created for learning rather than as a production application.

After completing the main learning objectives, I decided not to spend additional time polishing and expanding the project. I wanted to use that time to explore other areas of development, particularly **web design and UI development**.

The project can be continued in the future if needed.

> The biggest outcome of this project was not the application itself, but learning how to build, structure, debug, and maintain a full-stack project.
